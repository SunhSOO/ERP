# 설계 기준선 승인 기록

- 프로젝트: Luminode ERP Platform(LEP)
- 승인일: 2026-08-05
- 승인 방식: 대화상 사용자 승인
- 승인 대상: 통합 상세설계서, ADR-001~ADR-015, 작업 패키지 71개
- 다음 단계: 구현 계획 수립 및 Phase 0 기반 플랫폼 착수 준비

## 승인된 핵심 기준

1. 전체 전사 모듈은 모두 설계하되 Phase 0~7 순서로 활성화한다.
2. 초기 구조는 FastAPI/Python + Next.js/TypeScript 기반 모듈형 모놀리스다.
3. PostgreSQL을 업무 데이터 기준 원장으로 사용한다.
4. 파일·검색·벡터·큐는 MinIO·OpenSearch·Qdrant·Redis를 사용한다.
5. 자체 서버는 Docker Compose로 시작하고 실제 확장 필요가 확인될 때만 k3s를 검토한다.
6. ERP 핵심 연결 축은 프로젝트다.
7. 법정 회계·급여·세무는 전문 시스템 연동을 우선한다.
8. AI는 데이터베이스를 직접 수정하지 않고 승인된 Tool API만 사용한다.
9. 금전·계약·인사·권한·외부 발송·대량 변경은 사람 승인 후 실행한다.
10. 핵심 데이터는 물리 삭제보다 취소·무효·보관 상태를 사용한다.

## 변경 관리

이 기준선을 변경하려면 `DECISIONS.md`에 새로운 ADR을 추가하고 영향받는 설계·작업 패키지·테스트를 함께 갱신한다.
